# Prompt Engineering Hands-On Project

## Project Overview

This project demonstrates the application of prompt engineering techniques
to create high-quality marketing content using ChatGPT.

## Created By

**Name:** Rushikesh Karche

## Project Objective

The objective of this project is to design, test, and evaluate optimized
prompts using different prompt engineering techniques.

The project covers six content types:

- Blog Posts
- LinkedIn Posts
- Email Campaigns
- Instagram Captions
- YouTube Video Scripts
- Product Descriptions

## Prompt Engineering Techniques Used

| Content Type | Technique |
|---|---|
| Blog Post | RGCCO + Style Transfer |
| LinkedIn Post | Role Prompting + Zero-Shot |
| Email Campaign | One-Shot Prompting |
| Instagram Caption | Few-Shot Prompting |
| YouTube Script | Role Prompting + RGCCO |
| Product Description | Few-Shot Prompting |

## Project Files

### prompt_library.md
Contains the six optimized prompt templates used for generating the
marketing content.

### generated_content.md
Contains the final outputs generated using the optimized prompts.

### improvement_report.md
Contains the Before vs After quality comparison and the analysis of
the improvements made to each prompt.

### README.md
Provides an overview of the project and instructions for using the
prompt templates.

## How to Use the Prompt Templates

1. Open `prompt_library.md`.
2. Select the required content type.
3. Copy the corresponding optimized prompt.
4. Replace the placeholder values such as `[Insert Topic]`,
   `[Insert Product]`, or `[Insert Specs]` with your own information.
5. Paste the completed prompt into ChatGPT.
6. Review and refine the generated output if required.
